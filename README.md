# tic-tac-toe
Tic-Tac-Toe is a simple two-player strategy game played on a 3×3 grid. One player uses the symbol X, and the other uses O. Players take turns placing their symbol in an empty cell of the grid. The objective is to be the first player to place three of their symbols in a row, either horizontally, vertically, or diagonally
